# LXSJ — 智能助盲导盲车（STM32H750）

大学生嵌入式竞赛项目。基于 **STM32H750VBT6** 的智能导盲/助残小车，集成多传感器融合避障、视觉路况识别、语音交互与无线遥控功能，面向视障人群的出行辅助场景。

---

## 一、功能特性

| 功能模块 | 说明 |
| --- | --- |
| 超声波避障 | HC-SR04 + TIM2 输入捕获，实时测距并语音播报 |
| 惯性导航 | JY901S 九轴陀螺仪，航向角闭环 PID，支持精确 90° 原地转向 |
| 激光测距 | VL53L0X ToF 传感器，近距离障碍辅助判断 |
| 视觉路况识别 | 通过串口接入视觉模块（MV），识别盲道/斑马线/楼梯/可通行区域/红绿灯 |
| 语音交互 | UART8 语音模块，支持 0x01~0x0C 指令控制（前进、后退、转向、绕行、模式切换等） |
| 蓝牙遥控 | USART6 蓝牙模块，支持 0x01~0x0F 指令（含调速 300/350/400/450） |
| 无线回传 | ESP8266 / ESP32 双通道，向上位机回传路况与状态 |
| 环境感知 | DHT11 温湿度采集与语音播报 |
| 声源定位 | ADC1 + DMA 四路麦克风阵列，声源方向检测 |
| 紧急求助 | SIM800C 4G 模块（Call 目录） |
| 状态指示 | LED 灯光秀、蜂鸣提示、跳舞动作（电机组合动作） |

## 四、编译与烧录

1. 打开 `MDK-ARM/LTZH_Car.uvprojx`
2. 选择目标 `LTZH_Car`，执行 **Rebuild**
3. 使用 ST-Link / J-Link 下载至 STM32H750VBT6
4. 上电后延时 2 s 初始化，随后进入主循环（自动避障、测距播报、陀螺仪控制、视频流传输等）

> 说明：`Drivers/CMSIS/DSP`、`NN`、`Core_A`、`docs` 等目录体积较大且 Keil 工程未引用，已在 `.gitignore` 中排除。若需完整 CMSIS 包，可重新用 CubeMX 生成或从 ARM 官方下载。

## 五、主要通信协议

### 5.1 语音模块（UART8）

| 指令 | 功能 | 指令 | 功能 |
| --- | --- | --- | --- |
| 0x01 | 前进 | 0x07 | 进入导盲模式 |
| 0x02 | 后退 | 0x08 | 进入救援模式 |
| 0x03 | 停止 | 0x09 | 观察信号灯 |
| 0x04 | 右转 90° | 0x0A | 向左绕行 |
| 0x05 | 左转 90° | 0x0B | 向右绕行 |
| 0x06 | 播报温湿度 | 0x0C | 观察路况 |

### 5.2 蓝牙模块（USART6）

| 指令 | 功能 | 指令 | 功能 |
| --- | --- | --- | --- |
| 0x01 | 前进 | 0x06~0x09 | 速度档位（300/350/400/450） |
| 0x02 | 后退 | 0x0A~0x0D | 左 / 右 / 上 / 下 |
| 0x03 | 停止 | 0x0E | 停止 |
| 0x04 / 0x05 | 左转 / 右转 | 0x0F | 居中 |

### 5.3 视觉模块回传指令（USART1 / USART3）

| 数据 | 含义 | 数据 | 含义 |
| --- | --- | --- | --- |
| 0x47 / 0x6C / 0x4C | 直行 / 左偏 / 航线左偏 | 0x45 / 0x46 | 红灯 / 绿灯 |
| 0x72 / 0x52 | 右偏 / 航线右偏 | 0x71 / 0x51 | 左可通行 / 右可通行 |
| 0x77 | 前方可通行 | 0x53 / 0x54 | 左侧楼梯 / 右侧楼梯 |
| 0x4B | 前方不可通行 | 0x44 / 0x5A | 左侧斑马线 / 右侧斑马线 |
| 0x55 / 0x41 | 前方楼梯 / 前方斑马线 | 0x56 / 0x76 | 左 / 右不可通行 |

## 六、软件架构

- **中断驱动**：所有串口采用 `HAL_UART_Receive_IT` 逐字节接收，在 `HAL_UART_RxCpltCallback` 中完成协议解析与状态机切换。
- **软定时调度**：TIM13 每 0.1 s 触发，驱动陀螺仪刷新、数据流节拍、灯光秀、跳舞动作、转向延时等技术任务。
- **闭环控制**：JY901S 航向角为反馈量，PID 输出映射为左右轮 PWM，实现直线修正与精确转角。
- **多传感器优先级**：视觉路况信息优先于本地传感器，本地红外/超声波用于紧急避障与逼退。

---

## 七、注意事项

- 工程依赖 **HSE 25 MHz** 外部晶振，否则 480 MHz 主频与串口波特率均会异常。
- `esp8266/esp8266.h` 中的 SSID / 密码为现场调试用热点，部署时请自行修改。
- CubeMX 生成代码请遵循「修改 `.ioc` → Generate Code → 再补充用户代码」的流程，避免手动改动导致重定义冲突。
